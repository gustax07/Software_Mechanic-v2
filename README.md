# 🏭 Sistema de Gestão para Oficinas Mecânicas

Sistema desktop desenvolvido em C# com Windows Forms, com foco no gerenciamento de cadastros e informações de uma oficina mecânica, como usuários, contratos, telefones e endereços.

Este projeto foi criado com fins educacionais e como parte do portfólio pessoal do desenvolvedor, explorando conceitos como:

- CRUD completo

- Interface dinâmica

- Organização em camadas

- Reutilização de componentes visuais

# 🛠️ Tecnologias Utilizadas
- C#

- Windows Forms

- SQL Server (ou outro banco relacional)

- Guna2 UI (interface gráfica)

- Git & GitHub


# 🧠 Conceitos aplicados

- Programação Orientada a Objetos (POO)

- CRUD com banco de dados

- Interface dinâmica (criação automática de campos - Modal)

- Uso de Dictionary para armazenamento temporário de dados entre telas

- Geração automática de campos utilizando Reflection

- Organização do projeto em camadas (Classes, Forms e Includes)

- Animações simples utilizando Timer

- Criação de MessageBox personalizados

- Programação assíncrona com async, Task e await

- Manipulação de DataTable e controles dinamicamente (TextBox, ComboBox e DateTimePicker)

# ⚠️ Avisos Importantes

Este projeto não é comercial.
Alguns ícones e componentes visuais utilizados podem exigir créditos aos autores originais.
Projeto destinado a estudo e portfólio.
